# **App Name**: Alligo

## Core Features:

- User Authentication: Secure user registration and login with role-based access control to manage app features.
- Service Booking: Allow users to book various services, like tech support or home cleaning, with integrated scheduling and payment options.
- Marketplace Listings: Enable businesses and freelancers to create and manage listings for products and services with detailed descriptions and images.
- Real-Time Location: Integrate a real-time map using the device's geolocation and display professionals and services based on proximity to the user.
- AI Recommendation Engine: Utilize AI to suggest relevant services and products to users, improving the user experience.
- Personalized Recommendations: Personalize recommendations to highlight the services that will likely appeal to the current user. The system will use a tool to conditionally consider items the user has previously viewed and other popular local options to enhance personalized offerings.
- Integrated Messaging: Facilitate direct communication between customers and service providers to discuss project details and handle bookings.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a modern and trustworthy feel.
- Background color: Very light indigo (#F5F3FF) for a clean and calm background.
- Accent color: Slate blue (#6366F1) to provide highlights without stealing attention.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern look.
- Use consistent and modern icons from Lucide to enhance UI clarity.
- Implement a grid-based layout for consistent spacing and alignment across the app.
- Use subtle transitions and animations to enhance user experience and provide visual feedback.
